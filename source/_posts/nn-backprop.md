**一句话理解**：神经网络就是多层“线性变换 + 非线性激活”叠在一起。训练时先**前向**算出预测和损失，再按**链式法则**把损失对每个参数的梯度一层层传回去（反向传播），用梯度更新参数。没有非线性激活，再多层也只等价于一个线性模型。

<!-- more -->

## 通俗类比

把神经网络想成一条流水线：

1. **前向传播**：原料（输入）经过一道道工序（每一层），最后出成品（预测）；
2. **算损失**：拿成品和标准答案比，算出“差了多少”；
3. **反向传播**：从最后一道工序往前追责——每道工序对自己的误差负多大责任（梯度）；
4. **更新参数**：按责任大小拧一拧每道工序的旋钮（权重），下次少出错。

**链式法则**就是“总责任 = 上游责任 × 本工序的放大倍数”，可以一路乘回去。

## 核心原理

### 1. 从感知机到多层网络

**感知机**（Rosenblatt）：一个线性分类器 $\hat y=\mathrm{sign}(w^\top x+b)$，只能分开线性可分的数据。经典的 **XOR 问题**（异或）单层感知机学不会，需要至少一层隐藏层。

现代前馈网络一层的计算：

<div>
$$z^{(l)}=W^{(l)}a^{(l-1)}+b^{(l)},\qquad a^{(l)}=g(z^{(l)})$$
</div>

$g$ 是非线性**激活函数**。把多层这样叠起来，就能逼近很复杂的函数（万能逼近定理给出了存在性，不保证好训练）。

### 2. 常见激活函数

| 激活 | 公式 | 特点 |
| --- | --- | --- |
| Sigmoid | $\sigma(z)=1/(1+e^{-z})$ | 输出 (0,1)；两端饱和，导数最大只有 0.25，深层易梯度消失 |
| Tanh | $\tanh(z)$ | 输出 (−1,1)，零中心；仍会饱和 |
| ReLU | $\max(0,z)$ | 正半轴导数为 1，缓解梯度消失；负半轴恒为 0，可能出现“死 ReLU” |
| Leaky ReLU / GELU / SiLU | 变体 | 负半轴不完全为 0，或更平滑 |

Goodfellow《Deep Learning》第 6 章指出：现代深度网络默认推荐 ReLU 及其变体；sigmoid/tanh 在隐层中已较少单独使用（但 sigmoid 仍常用于二分类输出层，softmax 用于多分类输出层）。

### 3. 损失函数

- **回归**：均方误差 $\mathrm{MSE}=\frac{1}{n}\sum_i(y_i-\hat y_i)^2$。
- **二分类**：二元交叉熵 $-\big[y\log p+(1-y)\log(1-p)\big]$，其中 $p=\sigma(z)$。
- **多分类**：先对 logits 做 softmax 得到概率，再算交叉熵 $-\sum_k y_k\log p_k$。

一个重要技巧：sigmoid/softmax 与交叉熵组合时，对 logits 的梯度恰好是 $p-y$（Goodfellow《Deep Learning》与多数框架实现一致）。所以框架会提供融合算子（如 `binary_cross_entropy_with_logits`），既数值稳定又计算方便。

### 4. 反向传播与链式法则

目标：求损失 $L$ 对每个权重的偏导。以一层为例，$L$ 依赖 $a$，依赖 $z$，依赖 $W$：

<div>
$$\frac{\partial L}{\partial W}=\frac{\partial L}{\partial a}\cdot\frac{\partial a}{\partial z}\cdot\frac{\partial z}{\partial W}$$
</div>

多层时，从输出层开始，把“上游传来的梯度”乘上本层的局部导数，再传给更前面的层——这就是**反向传播（backpropagation）**。它本身不是一种优化算法，只是**高效计算梯度的方法**；真正更新参数的是 SGD、Adam 等优化器。

计算图视角：每个运算节点知道自己的局部梯度；反向时沿图反向遍历，把梯度累加起来。自动微分（autograd）做的就是这件事。

### 5. 梯度消失与梯度爆炸

反向传播时，梯度要连乘多层的局部导数：

- **梯度消失**：很多因子小于 1（如 sigmoid 导数 ≤ 0.25），连乘后梯度指数级变小，前面层几乎学不动。
- **梯度爆炸**：很多因子大于 1，梯度变得极大，参数更新一步就飞了。

常见对策：

| 问题 | 对策 |
| --- | --- |
| 消失 | 用 ReLU 等；残差连接；LSTM/GRU 的门控；BatchNorm/LayerNorm；合理初始化 |
| 爆炸 | 梯度裁剪（clipping）；合理初始化；降低学习率 |

sigmoid 导数最大值：$\sigma'(0)=\sigma(0)(1-\sigma(0))=0.25$。连乘 10 层，上限是 $0.25^{10}\approx 10^{-6}$——这就是“深层 + sigmoid ≈ 前面层学不动”的定量直觉。

## 小例子：用纯 NumPy 手写反向传播学 XOR

本机实际运行通过。单层感知机学不会 XOR；加一层隐藏层（tanh）+ 输出层（sigmoid + 交叉熵）就能学会。同时做了数值梯度检查，验证解析梯度算对了。

```python
import numpy as np
rng = np.random.RandomState(0)
X = np.array([[0,0],[0,1],[1,0],[1,1]], dtype=float)
y = np.array([[0],[1],[1],[0]], dtype=float)   # XOR
W1 = rng.randn(2, 4); b1 = np.zeros((1, 4))
W2 = rng.randn(4, 1); b2 = np.zeros((1, 1))
sig = lambda z: 1/(1+np.exp(-z))
lr = 1.0
for step in range(5001):
    z1 = X @ W1 + b1; h = np.tanh(z1)
    z2 = h @ W2 + b2; p = sig(z2)
    loss = -np.mean(y*np.log(p) + (1-y)*np.log(1-p))
    dz2 = (p - y) / len(X)                # sigmoid+交叉熵 的梯度是 p-y
    dW2 = h.T @ dz2; db2 = dz2.sum(0, keepdims=True)
    dh = dz2 @ W2.T
    dz1 = dh * (1 - h**2)                 # tanh'(z)=1-tanh^2
    dW1 = X.T @ dz1; db1 = dz1.sum(0, keepdims=True)
    for P, G in [(W1,dW1),(b1,db1),(W2,dW2),(b2,db2)]:
        P -= lr * G
    if step % 1000 == 0:
        print(f"step {step}: loss={loss:.4f}")
print("预测:", p.round(3).ravel(), "真实:", y.ravel())

# 数值梯度检查
def f(W):
    h = np.tanh(X @ W + b1); p = sig(h @ W2 + b2)
    return -np.mean(y*np.log(p) + (1-y)*np.log(1-p))
eps = 1e-6; i, j = 0, 0
Wp = W1.copy(); Wp[i,j] += eps; Wm = W1.copy(); Wm[i,j] -= eps
z1 = X @ W1 + b1; h = np.tanh(z1); p = sig(h @ W2 + b2)
dW1 = X.T @ (((p-y)/len(X)) @ W2.T * (1-h**2))
print("解析梯度", round(dW1[i,j], 8), " 数值梯度", round((f(Wp)-f(Wm))/(2*eps), 8))
print("sigmoid 导数最大值:", sig(0)*(1-sig(0)), " 连乘 10 层后上限:", 0.25**10)
```

本机输出：

```
step 0: loss=0.8381
step 1000: loss=0.0027
...
step 5000: loss=0.0004
预测: [0.    0.999 1.    0.001] 真实: [0. 1. 1. 0.]
解析梯度 -1.305e-05  数值梯度 -1.305e-05
sigmoid 导数最大值: 0.25  连乘 10 层后上限: 9.5367431640625e-07
```

怎么读：网络学会了 XOR（四个点预测几乎等于真实标签）；解析梯度与数值梯度吻合到小数点后多位，说明反向传播公式写对了；sigmoid 连乘 10 层后梯度上限约 $10^{-6}$，直观解释了梯度消失。

## 常见误区

1. **“反向传播是一种优化算法”**：它只负责算梯度；优化算法是 SGD/Adam 等。
2. **“多层线性层就比单层强”**：没有非线性激活时，$W_2 W_1 x$ 仍是线性变换，表达能力不增加。
3. **“Sigmoid 导数最大是 1”**：最大值是 0.25，这是它容易导致梯度消失的原因之一。
4. **“ReLU 没有任何问题”**：负半轴梯度为 0，神经元可能“死亡”；可用 Leaky ReLU 等缓解。
5. **“损失小就一定泛化好”**：训练损失低可能过拟合，还要看验证集。
6. **“softmax 输出可以直接当校准概率”**：排序通常可信，概率是否校准要另做检验。

## 面试口径

**30 秒版**：神经网络是多层线性变换加非线性激活。训练分前向算损失、反向按链式法则传梯度、再用优化器更新。sigmoid/tanh 易饱和导致梯度消失，现代隐层多用 ReLU。回归用 MSE，分类用交叉熵；sigmoid/softmax 配交叉熵时对 logits 的梯度是 $p-y$。反向传播不是优化器，只是高效求梯度的算法。

**2 分钟版**：先讲感知机只能线性可分、XOR 需要隐藏层。再讲一层的 $z=Wa+b$、$a=g(z)$，强调非线性的必要性。然后讲反向传播：计算图上每个节点有局部导数，损失梯度从输出往输入流，复杂度与前向同阶。接着讲梯度消失/爆炸的成因（连乘）和对策（ReLU、残差、归一化、初始化、梯度裁剪）。最后提一句：交叉熵 + logits 的融合实现既数值稳定，又让梯度形式简洁。

## 面试高频问答

**Q1：为什么神经网络需要非线性激活函数？**
没有非线性，多层线性变换的复合仍是一个线性变换，表达能力不随深度增加。非线性让网络能逼近复杂函数。

**Q2：反向传播在算什么？和梯度下降什么关系？**
反向传播用链式法则高效计算损失对每个参数的梯度；梯度下降（或 Adam 等）用这些梯度去更新参数。前者算梯度，后者用梯度。

**Q3：sigmoid 为什么容易导致梯度消失？**
两端饱和，导数接近 0，最大值只有 0.25。多层连乘后梯度指数级衰减，底层参数几乎得不到有效更新。

**Q4：ReLU 的优点和缺点？**
优点：正半轴导数为 1，缓解消失；计算简单。缺点：负半轴梯度为 0，可能导致死神经元；输出非零中心。

**Q5：交叉熵损失对 logits 的梯度为什么是 $p-y$？**
对 sigmoid/softmax 与交叉熵求复合导数后，中间项相消，只剩下预测概率减真实标签。这也是框架提供 `*_with_logits` 接口的原因之一。

**Q6：什么是梯度爆炸？怎么处理？**
反向传播时梯度连乘变得极大，参数更新失控。常用梯度裁剪、更合理的初始化、降低学习率、用残差/门控结构。

**Q7：前向传播和反向传播的时间复杂度关系？**
同阶。反向传播每个节点计算局部梯度，总计算量通常是前向的常数倍（经验上大约几倍），不会差一个数量级以上。

**Q8：万能逼近定理说了什么？没说什么？**
说一层足够宽的隐藏层网络可以逼近任意连续函数（在一定条件下）。它不保证能有效训练出这样的网络，也不说明深度没有好处。

## 自测题

1. 去掉所有激活函数，一个 10 层全连接网络等价于什么？
2. 写出 sigmoid 的导数，并指出最大值。
3. 为什么数值梯度检查能验证反向传播是否写对？
4. 分类任务的输出层常用什么激活 + 什么损失？
5. 残差连接为什么有助于缓解梯度消失？

<details>
<summary>参考答案要点</summary>

1. 等价于一个单层线性变换（所有权重矩阵连乘并吸收偏置）。
2. $\sigma'(z)=\sigma(z)(1-\sigma(z))$，在 $z=0$ 处取最大值 0.25。
3. 用定义 $\partial L/\partial w\approx\big(L(w+\varepsilon)-L(w-\varepsilon)\big)/(2\varepsilon)$ 做数值近似，与解析梯度对比；一致则实现大概率正确。
4. 二分类常用 sigmoid + 二元交叉熵；多分类常用 softmax + 交叉熵（或直接用带 logits 的融合损失）。
5. 残差提供一条“短路”：梯度可以通过恒等映射直接流回前面层，即使中间层局部导数很小，也不至于完全消失。

</details>
