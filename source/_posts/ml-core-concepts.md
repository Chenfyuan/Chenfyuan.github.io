**一句话理解**：机器学习就是让程序从数据里自动总结规律，目标不是把见过的题背下来，而是在**没见过的新数据**上也做得好。这篇讲的所有概念（数据划分、过拟合、偏差-方差、正则化、交叉验证）都围绕这一个目标：**泛化能力**。

<!-- more -->

## 通俗类比

把模型想成一个备考的学生：

- **训练集**是平时的练习题，学生可以反复做、对答案；
- **验证集**是模拟考，用来决定“该用哪套复习方法”（调超参数、选模型）；
- **测试集**是最终的高考，只能考一次，用来客观报告真实水平。

**过拟合**就是死记硬背：练习题全对，换一套题就不会。**欠拟合**是根本没学会：练习题都做不对。**正则化**相当于老师说“别背答案，理解思路”，强行让学生学得简单一点。

## 核心原理

### 1. 监督学习与无监督学习

- **监督学习**：每条数据都有“标准答案”（标签）。预测类别叫**分类**（垃圾邮件/正常邮件），预测连续数值叫**回归**（房价）。
- **无监督学习**：数据没有标签，让模型自己找结构，比如**聚类**（K-Means 把用户分群）、**降维**（PCA 把高维数据压缩）。
- 此外还有**强化学习**（智能体通过与环境交互、根据奖励学习）和**自监督学习**（从数据本身构造标签，例如大语言模型“预测下一个词”）。Goodfellow《Deep Learning》第 5 章对监督/无监督有系统讲解。

### 2. 训练集、验证集、测试集

| 数据集 | 用途 | 能不能拿来调参 |
| --- | --- | --- |
| 训练集 | 学习模型参数（权重） | 是 |
| 验证集 | 选模型、调超参数、早停 | 是 |
| 测试集 | 最终评估，报告泛化性能 | **不能** |

关键原则：**测试集在整个开发过程中不能参与任何决策**。如果你反复看测试集成绩去调参，测试集就变成了“另一个验证集”，报告的分数会偏乐观。

划分比例没有统一标准（**常见做法**是 8:1:1 或 7:1.5:1.5，数据量很大时验证/测试比例可以更小）。分类任务常用**分层抽样**（stratify），让各集合里类别比例一致；时间序列要**按时间切**，不能随机打乱，否则会用“未来”预测“过去”。

### 3. 过拟合与欠拟合

- **欠拟合**：训练误差高，验证误差也高 → 模型太简单或训练不够。
- **过拟合**：训练误差很低，验证误差明显更高 → 模型把训练数据里的噪声也记住了。

| 症状 | 常见对策 |
| --- | --- |
| 欠拟合 | 用更复杂的模型、加特征、训练更久、减小正则化 |
| 过拟合 | 加数据/数据增强、正则化、降低模型复杂度、早停、Dropout、集成 |

### 4. 偏差-方差权衡

对平方损失，期望预测误差可以分解为三部分（Goodfellow《Deep Learning》第 5 章有推导和讨论）：

<div>
$$\mathbb{E}\big[(y-\hat f(x))^2\big]=\underbrace{\big(\mathbb{E}[\hat f(x)]-f(x)\big)^2}_{\text{偏差}^2}+\underbrace{\mathbb{E}\big[(\hat f(x)-\mathbb{E}[\hat f(x)])^2\big]}_{\text{方差}}+\underbrace{\sigma^2}_{\text{不可约噪声}}$$
</div>

这里期望是对“不同训练集”取的，$f$ 是真实函数，$\sigma^2$ 是数据本身的噪声。

- **偏差**：模型平均来看离真相有多远 → 太简单的模型偏差大（欠拟合）。
- **方差**：换一份训练数据，模型变化有多大 → 太复杂的模型方差大（过拟合）。
- 通常模型复杂度上升，偏差下降、方差上升，所以要找一个折中点。

> 注意：深度学习里观察到的“双下降”（double descent）现象说明，非常大的模型并不总是遵循经典的 U 形曲线。这一点学界仍在研究，面试中提一句即可，不要说成定论。

### 5. 正则化：L1 与 L2

在损失函数上加一项惩罚模型复杂度：

<div>
$$J(w)=\text{Loss}(w)+\lambda\,\Omega(w)$$
</div>

- **L2（岭回归 Ridge / 权重衰减）**：$\Omega(w)=\|w\|_2^2=\sum_i w_i^2$。让权重整体变小但一般不会正好为 0，解更平滑。
- **L1（Lasso）**：$\Omega(w)=\|w\|_1=\sum_i |w_i|$。倾向于让一部分权重**正好变成 0**，相当于自动做特征选择，得到稀疏解。
- **Elastic Net**：L1 和 L2 的组合。

为什么 L1 会产生稀疏解？几何直觉：L1 的约束区域是“菱形”（高维是多面体），有尖角落在坐标轴上，损失函数的等高线更容易先碰到尖角，那里某些坐标正好为 0；L2 的约束区域是圆，没有尖角。scikit-learn 线性模型文档对 Lasso 的稀疏性有说明。

$\lambda$ 越大惩罚越强：过大会欠拟合，过小起不到作用，一般用验证集或交叉验证来选。

### 6. 交叉验证

数据不多时，只切一次验证集，结果受“运气”影响大。**K 折交叉验证**：

1. 把训练数据分成 K 份；
2. 轮流用其中 1 份做验证，其余 K-1 份训练；
3. 得到 K 个分数，取平均（也看标准差）。

scikit-learn 文档中的要点：

- 交叉验证用于**模型选择和调参**，最终仍应在独立测试集上评估；
- 分类常用 `StratifiedKFold`（保持类别比例）；
- 同一个用户/病人的多条数据要用 `GroupKFold`，避免同一组同时出现在训练和验证里；
- 时间序列用 `TimeSeriesSplit`。

**数据泄漏**是最常见的坑：比如先用全部数据做标准化或特征选择，再做交叉验证，验证集的信息就已经“漏”进了训练。正确做法是把预处理放进 `Pipeline`，让它在每一折内部只用训练部分拟合。

## 小例子：用代码看过拟合、交叉验证和 L1/L2

下面代码在本机用 scikit-learn 1.9.1 实际运行过（结果会随版本和随机种子略有不同）：

```python
import numpy as np
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression, Lasso, Ridge
from sklearn.tree import DecisionTreeClassifier

X, y = load_breast_cancer(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, random_state=0, stratify=y)

# 1) 过拟合：不限深度的决策树 vs 限制深度
for depth in [None, 3]:
    t = DecisionTreeClassifier(max_depth=depth, random_state=0).fit(X_tr, y_tr)
    print(f"max_depth={depth}: 训练准确率={t.score(X_tr,y_tr):.3f}, 测试准确率={t.score(X_te,y_te):.3f}")

# 2) 5 折交叉验证（只在训练集上做，预处理放进 Pipeline 防泄漏）
clf = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))
scores = cross_val_score(clf, X_tr, y_tr, cv=5)
print("5 折 CV 准确率：", np.round(scores, 3), "均值", round(scores.mean(), 3))

# 3) L1 让系数变成 0，L2 只让系数变小
rng = np.random.RandomState(0)
Xr = rng.randn(200, 10)
yr = 3*Xr[:, 0] - 2*Xr[:, 1] + 0.5*rng.randn(200)   # 只有前 2 个特征有用
print("Lasso(L1) 系数为 0 的个数：", int(np.sum(Lasso(alpha=0.1).fit(Xr, yr).coef_ == 0)))
print("Ridge(L2) 系数为 0 的个数：", int(np.sum(Ridge(alpha=1.0).fit(Xr, yr).coef_ == 0)))
```

本机输出：

```
max_depth=None: 训练准确率=1.000, 测试准确率=0.939
max_depth=3: 训练准确率=0.974, 测试准确率=0.921
5 折 CV 准确率： [0.956 0.967 0.989 0.956 0.978] 均值 0.969
Lasso(L1) 系数为 0 的个数： 8
Ridge(L2) 系数为 0 的个数： 0
```

怎么读：不限深度的树训练集 100% 正确，这是典型的“背答案”信号（训练和测试之间有明显差距）。在这个小数据集上限制深度后测试分数并没有变高——**说明正则化不一定每次都提升分数，要用验证集/交叉验证来决定**，而不是想当然。L1 把 8 个无用特征的系数压成了 0，L2 一个也没压到 0，这正是两者的典型区别。

## 常见误区

1. **“训练集准确率高就是好模型”**：要看验证/测试集，训练集高而验证集低就是过拟合。
2. **“用测试集调参没关系”**：会让测试成绩偏乐观，失去“最终考试”的意义。
3. **“先对全量数据标准化再划分”**：这是数据泄漏，预处理只能在训练部分拟合。
4. **“L2 也能做特征选择”**：L2 通常只把权重变小，不会正好变成 0；做稀疏/特征选择用 L1。
5. **“时间序列可以随机 K 折”**：会用未来信息预测过去，应按时间顺序切分。
6. **“正则化越强越好”**：太强会欠拟合，强度要通过验证来选。

## 面试口径

**30 秒版**：机器学习的目标是泛化。数据分成训练、验证、测试三份：训练集学参数，验证集调超参，测试集只用于最终评估。训练好、验证差是过拟合，两边都差是欠拟合。误差可以分解为偏差、方差和噪声，模型越复杂偏差越小方差越大。正则化（L1 稀疏、L2 收缩）和交叉验证是控制过拟合、可靠选模型的两大工具。

**2 分钟版**：在 30 秒版基础上展开三点。第一，划分细节：分类用分层抽样，分组数据用 GroupKFold，时间序列按时间切；所有预处理放进 Pipeline 防止数据泄漏。第二，诊断：对比训练和验证曲线，欠拟合就加复杂度/特征，过拟合就加数据、正则化、早停、降复杂度。第三，正则化：L1 的约束区域有尖角，容易得到稀疏解，适合特征选择；L2 让权重平滑变小，对共线性更稳；λ 用交叉验证选。最后补一句：深度学习中观察到双下降现象，经典 U 形曲线并不总成立，这仍是研究话题。

## 面试高频问答

**Q1：监督学习和无监督学习的区别？**
监督学习有标签，学的是从输入到标签的映射，分类和回归是典型任务；无监督学习没有标签，目标是发现数据结构，例如聚类、降维。

**Q2：为什么需要验证集，只有训练集和测试集不行吗？**
调超参和选模型本身就是在“用数据做决策”。如果用测试集做这些决策，测试集信息就泄漏进了模型选择过程，最终报告的成绩会偏乐观。验证集专门承担这个角色。

**Q3：如何判断过拟合和欠拟合？**
看训练误差和验证误差：训练低、验证明显高是过拟合；两者都高是欠拟合。画学习曲线（随训练样本数或训练轮数变化）最直观。

**Q4：解释偏差-方差权衡。**
期望误差 = 偏差² + 方差 + 不可约噪声。偏差衡量模型平均预测离真实值多远，方差衡量模型对训练数据变化的敏感程度。简单模型偏差大方差小，复杂模型偏差小方差大，要找总误差最小的折中点。

**Q5：L1 和 L2 正则化有什么区别？**
L1 惩罚绝对值之和，倾向于产生稀疏解，可做特征选择；L2 惩罚平方和，让权重整体变小、更平滑，一般不为 0。几何上 L1 约束区域有落在坐标轴上的尖角。

**Q6：K 折交叉验证怎么做，K 怎么选？**
把数据分 K 份，轮流 1 份验证、K-1 份训练，取 K 次结果的均值和标准差。K 越大，每次训练用的数据越多，但计算量越大；5 或 10 是常见取值，属于经验做法，没有理论上的唯一最优。

**Q7：什么是数据泄漏？举个例子。**
训练时用到了预测时拿不到的信息。比如先在全量数据上做标准化再切分、特征里含有“事后才知道”的字段、同一用户的数据同时出现在训练和验证中。结果是离线指标虚高、上线效果差。

**Q8：除了正则化，还有哪些方法缓解过拟合？**
增加数据或数据增强、降低模型复杂度（如限制树深度）、早停、集成学习（如随机森林）、神经网络中的 Dropout 等。

## 自测题

1. 训练准确率 99%，验证准确率 70%，最可能是什么问题？给出两个对策。
2. 为什么 L1 正则化能做特征选择？
3. 一份病人数据，每个病人有多条记录，交叉验证时应该注意什么？
4. 偏差-方差分解里的“不可约噪声”能通过换更好的模型消除吗？
5. 在交叉验证之前对全部数据做了特征选择，会有什么问题？

<details>
<summary>参考答案要点</summary>

1. 过拟合。可以加数据/数据增强、加正则化、降低模型复杂度、早停等。
2. L1 的约束区域在坐标轴上有尖角，最优解容易落在尖角处，使部分权重正好为 0，对应的特征就被“删掉”了。
3. 要按病人分组（如 GroupKFold），保证同一病人的数据只出现在训练或验证的一侧，否则会高估效果。
4. 不能。它来自数据本身的随机性，与模型无关，是误差的下限。
5. 数据泄漏：验证折的信息已经参与了特征选择，交叉验证分数会偏乐观。应把特征选择放进 Pipeline，在每折内部只用训练部分完成。

</details>
