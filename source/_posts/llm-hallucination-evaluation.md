**一句话理解**：幻觉（Hallucination）是大模型生成**看起来很流畅、很自信，但与事实不符或与给定内容不一致**的内容；评估就是用系统化的方法衡量模型回答的好坏，包括用另一个大模型当“评委”。

<!-- more -->

## 通俗类比

大模型像一个特别会说话、从不说“我不知道”的学生。遇到不会的题，他也能写出一段语句通顺、格式完美的答案，引用的“文献”看起来像模像样，但可能根本不存在。

评估就像阅卷：可以对标准答案（自动指标），可以请老师打分（人工评估），也可以请一位“学霸同学”帮忙打分（LLM-as-a-Judge）。但这位同学有自己的偏好，比如更喜欢写得长的答案。

## 核心原理

### 1. 幻觉的分类

根据 Huang 等人的综述（2023），大模型幻觉可分为两大类：

| 类型 | 含义 | 例子 |
| --- | --- | --- |
| **事实性幻觉**（Factuality） | 与真实世界事实不一致，或编造无法验证的内容 | 说错某个历史事件的年份；编造不存在的论文 |
| **忠实性幻觉**（Faithfulness） | 与用户指令、给定上下文不一致，或自身逻辑矛盾 | 让它总结文档，它加进了文档里没有的内容；前后说法矛盾 |

### 2. 幻觉从哪来

综述把原因归到三个阶段：

| 阶段 | 原因举例 |
| --- | --- |
| 数据 | 训练数据有错误、偏见或过时；长尾知识学得不牢 |
| 训练 | 预训练和推理行为不一致；对齐阶段可能让模型**迎合用户**（谄媚，sycophancy），即使用户说错了也附和 |
| 推理 | 采样带随机性（温度越高越发散）；逐词生成时早期错误会延续下去 |

一个关键认识：模型的训练目标是**生成合理的下一个词**，而不是“只说真话”。流畅和正确是两回事。

### 3. 怎么检测幻觉

- **对照外部知识**：把回答拆成一条条原子事实，逐条去知识源中核验（FactScore 是这类思路的代表）；
- **自一致性检查**：对同一问题多次采样，如果答案彼此矛盾，很可能是幻觉（SelfCheckGPT 的思路）；
- **不确定性估计**：看模型生成时的概率或置信度；
- **忠实性检测**：用自然语言推理（NLI）模型或问答方法检查回答能否被原文支持；
- **大模型评委**：让另一个模型判断回答是否有依据。

常见的评测集包括 TruthfulQA（测试模型是否会复述常见误解）、HaluEval（幻觉识别）、FreshQA（考察时效性知识）等。

### 4. 怎么缓解幻觉

| 方向 | 方法 |
| --- | --- |
| 数据 | 清洗、过滤低质量数据 |
| 知识 | **RAG**：检索可靠资料再回答，并标注来源 |
| 推理时 | 降低采样温度；先生成答案再**自我验证**（如 Chain-of-Verification，先列核验问题再逐个回答，最后修正）；改进解码策略（如 DoLa、上下文感知解码等） |
| 提示词 | 明确要求“不知道就说不知道”“只依据给定资料” |
| 产品层 | 展示引用来源、关键场景人工复核 |

> 目前没有任何方法能**彻底消除**幻觉，只能降低。

### 5. 模型评估的几种方式

| 方式 | 说明 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 基于参考答案的自动指标 | 和标准答案比对，如精确匹配、准确率、F1，或 BLEU/ROUGE 这类文本重叠指标 | 便宜、可复现 | 开放式回答有多种正确写法，重叠指标难以衡量 |
| 人工评估 | 人按标准打分或两两比较 | 最贴近真实偏好 | 贵、慢，评审之间也可能不一致 |
| LLM-as-a-Judge | 用强大模型当评委打分 | 便宜、快、可扩展 | 存在系统性偏差 |
| 线上指标 | 用户反馈、A/B 测试 | 反映真实使用 | 噪声大、需要流量 |

几个常用指标的含义：

- **准确率**：答对的比例；
- **精确率 / 召回率**：

<div>
$$\text{Precision}=\frac{TP}{TP+FP},\qquad \text{Recall}=\frac{TP}{TP+FN},\qquad F_1=\frac{2\cdot\text{Precision}\cdot\text{Recall}}{\text{Precision}+\text{Recall}}$$
</div>

其中 TP 是真正例、FP 是假正例、FN 是假反例。精确率看“说是的里面有多少真的是”，召回率看“真的是的里面找到了多少”，F1 是两者的调和平均。

### 6. LLM-as-a-Judge 及其偏差

Zheng 等人（2023）的论文系统研究了用大模型当评委，提出三种用法：

1. **两两比较**（pairwise）：给两个回答，问哪个更好；
2. **单答案打分**（single answer grading）：直接给一个回答打分；
3. **参考答案引导**（reference-guided）：提供参考答案再判断。

论文指出的主要偏差：

| 偏差 | 表现 | 缓解方法 |
| --- | --- | --- |
| **位置偏差** | 倾向于偏爱某个位置（如第一个）的回答 | 交换两个回答的位置各评一次，结果不一致记为平局 |
| **冗长偏差** | 偏爱更长的回答，即使没有更好 | 评分标准明确“长不等于好”，结合人工抽查 |
| **自我偏好** | 可能偏爱自己生成的回答（论文认为这一点证据**尚不确定**） | 用不同模型当评委 |
| **数学/推理评判能力有限** | 自己会做的题，评判时也可能被错误答案带偏 | 先让评委独立解题（思维链），或提供参考答案 |

论文的结论是：强大模型做评委与人类偏好有较高一致性，可以作为人工评估的**可扩展近似**，但需要配合偏差缓解手段。

## 常见误区

1. **“温度设为 0 就没有幻觉”**：只降低随机性，模型若本身“记错了”，仍会稳定地输出错误答案。
2. **“回答得越自信越可信”**：幻觉的典型特征恰恰是“自信地说错”。
3. **“用了 RAG 就没有幻觉”**：检索错误、模型不遵循资料都会导致幻觉。
4. **“LLM 评委打分就是客观标准”**：评委有位置、冗长等偏差，需要校准和人工抽检。
5. **“BLEU/ROUGE 高就说明回答好”**：重叠指标衡量的是字面相似，不能衡量事实正确性和有用性。

## 面试高频问答（30 秒版）

**Q1：什么是大模型幻觉？有哪些类型？**
生成流畅但与事实或上下文不符的内容。一类是事实性幻觉，与真实世界事实不符；一类是忠实性幻觉，与用户指令、给定上下文不一致或自相矛盾。

**Q2：幻觉产生的原因？**
数据层面：训练数据有错、过时，长尾知识学得少；训练层面：对齐可能导致迎合用户；推理层面：采样随机性和逐词生成的错误累积。根本上，模型优化的是“生成合理文本”，不是“保证真实”。

**Q3：如何缓解幻觉？**
RAG 提供可靠资料并要求引用；提示词允许说“不知道”；降低温度；生成后自我验证；在关键场景加人工复核。没有方法能完全消除。

**Q4：怎么检测幻觉？**
对照外部知识逐条核验原子事实；多次采样看自一致性；用 NLI 检查回答是否被原文支持；或用大模型当评委判断。

**Q5：什么是 LLM-as-a-Judge？有什么问题？**
用强大模型给其他模型的回答打分或比较，便宜且可扩展，与人类偏好一致性较高。问题是有位置偏差、冗长偏差、可能的自我偏好，以及评判数学推理的能力有限。

**Q6：怎么缓解位置偏差？**
交换两个回答的顺序各评一次，两次结论一致才采纳，不一致就记为平局。

**Q7：精确率和召回率的区别？**
精确率 = TP/(TP+FP)，衡量“预测为正的有多少是对的”；召回率 = TP/(TP+FN)，衡量“真正的正例找回了多少”。F1 是二者的调和平均。

**Q8：为什么开放式生成任务很难评估？**
同一问题有很多种正确回答，字面重叠指标难以衡量质量；人工评估准但贵；所以常结合人工评估、LLM 评委和线上反馈。

## 自测题

1. 让模型总结一篇文章，它补充了一个文章里没有、但真实存在的事实，这算哪类幻觉？
2. 为什么温度设为 0 不能彻底消除幻觉？
3. 两两比较时，评委总是选第一个回答，这是哪种偏差？怎么处理？
4. 某检测器 TP=40、FP=10、FN=40，精确率、召回率、F1 是多少？
5. SelfCheckGPT 的核心思路是什么？

<details>
<summary>参考答案要点</summary>

1. 忠实性幻觉（与给定上下文不一致），即使内容本身真实。
2. 温度只控制随机性；模型知识本身错误或缺失时会稳定输出错误。
3. 位置偏差；交换顺序各评一次，不一致记为平局。
4. 精确率 0.8，召回率 0.5，F1 = 2×0.8×0.5/1.3 ≈ 0.615。
5. 对同一问题多次采样，比较回答之间是否一致，不一致说明模型可能在“编”。
